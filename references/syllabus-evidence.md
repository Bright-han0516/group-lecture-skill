# Syllabus and past-paper evidence gate

Complete this check before planning chapters or selecting practice. Repeat it
before teacher handoff. It applies to the teaching body, formula and reference
sheets, definitions, examples, figures and captions, exam tips, original
exercises and both editions' explanations.

## Establish the assessment scope

Record the awarding body, subject and code, official specification version and
assessment years, level or tier, route/option where applicable, and exact
paper/component/unit. Read the applicable objectives, guidance and exclusions,
not just the topic title. Do not substitute another board, a domestic version
for an international one, another level, or a superseded specification.

Build `qa/syllabus_scope.md` before drafting. Map each assessed idea to a current
official specification clause or to a verified assessment application within
the current scope. A question-based application must use the actual question
paper (QP) and the corresponding official mark scheme (MS) or other official
scoring evidence. Match session, component/variant and question part. A verified
QP without an MS can still supply a practice item already mapped to a current
objective; solve independently and mark `NOT MS VERIFIED`. It cannot by itself
establish a new general requirement or an official solution.

A textbook, exam-board data booklet, topic tag, keyword match, AI summary or
author-written exercise cannot establish a new independent requirement. A data
booklet can show that something is provided; use the official assessment rules
to determine what must be known. Older questions can be normal practice only
when the current specification and the actual item are compatible at the
selected level/component. Label the old specification on the source line.
Do not turn a question's context, supplied relationship, or optional marking
route into a general recall requirement.

## Label what the student is expected to do

| Label | Evidence and treatment |
|---|---|
| **Recall / know** | The applicable specification or official assessment guidance supports independent knowledge. Teach it as an assessed requirement; only call an exact formula or wording mandatory to memorise when supported. |
| **Derive / justify** | The current objective or verified item asks for a derivation, explanation or inference. Teach the starting point and reasoning under the applicable assumptions; do not promote the result to compulsory recall without separate evidence. |
| **Given / use in context** | A relationship, model, text or other information is supplied in the item or official reference materials. Teach how to interpret or use it with the evidence it belongs to; do not add a standalone recall point because it appears in a question or score guide. |
| **Unverified / outside scope** | Missing primary evidence, wrong level/board/model, or excluded by guidance. Record the issue and omit from assessed content. Include explicitly requested enrichment only if clearly separated and labelled non-assessed, and do not present unauthenticated material as exam evidence. |

Use the specified model, approximations, definitions and prerequisites. For
example, if a question supplies a relation for a simplified model, the lesson
may teach its use in that item but must not present the relation or a more
advanced model as an independent syllabus requirement.

## Evidence map

Use this format in the course workspace, then link to it from
`qa/academic_review.md`. Include both in-scope items and decisions to exclude or
defer a proposed addition. The following placeholders are illustrative, not
exam citations, and must be replaced with actual references before delivery.

| Proposed content / use | Primary source and exact locator | Component, level, model/limit | Demand | Decision |
|---|---|---|---|---|
| Explain a specified relationship | Current official specification: version, clause and page | Selected component; stated assumptions only | Derive / justify | Keep derivation in main lesson; do not list its result as compulsory recall |
| Interpret a formula supplied in an exam item | Original QP and corresponding official scoring evidence: session, variant, question part and pages | Selected level; item-provided formula | Given / use in context | Keep original stem; explain use beside the item |
| More advanced model from supplementary reading | No applicable current clause or verified assessment use | Outside specified model | Unverified / outside scope | Exclude from main handout |

Preserve original QP/MS wording, figures, marks and fidelity in authorised
crops. If a separated subpart depends on prior text, figures, values or
instructions, include the relevant original context or add a separately
labelled context note beside the unaltered crop; do not silently edit either
source. Keep QP/MS evidence and private course material outside the public
skill repository.

Before delivery, cross-check both PDFs: the same limits must hold in prose,
formula lists, headings, captions, tips, question selections and answer keys.
Check both directions: every required objective is covered or flagged, and
every presented assessed point has adequate evidence. Structural PDF checks
do not enforce this judgment.
